# 여행 앱 - 페르소나 & 사용자 스토리

## 페르소나

### 1. 혜민 (기획자 겸 메인 입력자)
- 비개발자, 여행 준비를 주도하는 쪽. 여행 전 구글시트에 목적지/기간/주소/주차 정보를 입력.
- 여행 중에는 남편과 함께 앱으로 오늘 일정을 확인하는 용도로도 사용.
- 니즈: 입력은 쉽고 편한 시트로, 결과는 예쁘고 직관적인 모바일 화면으로.

### 2. 민재 (남편, 공동 입력자 겸 실사용자)
- 시트에 직접 일정을 추가/수정할 수 있음 (예: 본인이 예약한 숙소나 렌터카 정보).
- 여행 중 실시간으로 "오늘 뭐 하지, 다음 장소 어디지, 주차는 어디에 하지"를 앱에서 확인.
- 니즈: 운전 중이거나 이동 중에도 한눈에 보이는 화면, 주소 탭하면 바로 구글지도 연결.

### 공통 사용 시나리오
- 여행 전: 구글시트에 일정 입력 (시간, 장소명, 주소, 이동수단, 메모, 예약번호, 주차 위치/요금/특이사항)
- 여행 중: 앱 열어서 오늘 일정 확인, 주소 탭 → 구글지도 이동, 인터넷 안 터지는 구간에서도 마지막으로 불러온 일정은 오프라인으로 확인 가능
- 여행 후: 지난 여행 목록에서 다시 열어볼 수 있음 (여러 건 관리)

## 요구사항 요약
- 입력: 구글시트 (혜민+민재 둘 다 편집 가능)
- 관리 단위: 여러 건의 여행 (여행 목록 → 상세)
- 사용 시점: 여행 중 실시간 확인이 메인
- 오프라인: 마지막으로 불러온 일정은 오프라인에서도 확인 가능 (PWA 캐싱)
- 지도 연동: 주소 탭 → 구글지도
- 알림/텔레그램 연동: 불필요, 앱만으로 충분
- 주차 정보: 위치 + 요금 + 특이사항
- 일정 항목 필드: 시간/장소명/주소 (기본) + 메모/이동수단/예약번호
- 추가 기능: 준비물 체크리스트
- 프로젝트: 기존 예나콩 가족앱과 별도의 새 프로젝트

## 사용자 스토리

### 여행 관리
- US1. 사용자로서, 여러 개의 여행을 목록으로 보고 그 중 하나를 선택해서 상세 일정을 볼 수 있다.
- US2. 사용자로서, 지금 진행 중인 여행이 있으면 앱을 열었을 때 바로 그 여행이 보였으면 좋겠다.

### 일정 입력 (구글시트)
- US3. 혜민 또는 민재로서, 구글시트에 새 행을 추가해서 일정 항목(시간/장소명/주소/이동수단/메모/예약번호)을 등록할 수 있다.
- US4. 혜민 또는 민재로서, 구글시트에서 기존 일정을 수정하면 앱에도 반영된다.
- US5. 혜민 또는 민재로서, 시트에 주차 정보(위치/요금/특이사항)를 별도로 입력할 수 있다.

### 일정 조회 (앱)
- US6. 사용자로서, 여행 중 오늘 날짜의 일정을 시간순으로 한눈에 볼 수 있다.
- US7. 사용자로서, 일정 항목의 장소 주소를 탭하면 구글지도 앱/웹으로 바로 연결된다.
- US8. 사용자로서, 일정 항목에 딸린 메모나 예약번호를 확인할 수 있다.
- US9. 사용자로서, 해당 날짜에 주차 정보가 있으면 일정과 함께 위치/요금/특이사항을 볼 수 있다.

### 오프라인 지원
- US10. 사용자로서, 인터넷이 안 되는 상황에서도 마지막으로 불러온 일정을 앱에서 볼 수 있다.
- US11. 사용자로서, 오프라인 상태일 때 "오프라인 모드"임을 알 수 있어 데이터가 최신이 아닐 수 있음을 인지한다.

### 체크리스트
- US12. 사용자로서, 여행별로 준비물 체크리스트를 만들고 체크할 수 있다.
- US13. 혜민 또는 민재로서, 체크리스트 항목도 구글시트(또는 앱 내)에서 추가/수정할 수 있다.

## 참고: 입력 방식 변경
US3~US5, US13에 적힌 "구글시트에 직접 입력"은 초기 아이디어였고, 이후 브레인스토밍에서 **앱 안의 전용 입력 화면(커스텀 폼)에서 입력 → 내부적으로 구글시트에 저장**하는 방식으로 확정됨. 구글시트는 화면에 노출되지 않는 데이터 저장소 역할. 자세한 내용은 `2026-08-04-travel-app-implementation-design.md` 참고.

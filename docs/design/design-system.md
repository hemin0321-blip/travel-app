## 타이포그래피

- Display/Body: `Apple SD Gothic Neo, Malgun Gothic, Pretendard, system-ui`
- Mono (날짜·예약번호): `JetBrains Mono, SF Mono, Consolas`
- 스케일: H1(800, 1.4–2rem) → Title(800, 1.0–1.15rem) → Body(700, .8rem) → Meta(400, .72rem) → Micro/Chip(700, .64rem) → Mono(700, .7rem)

## 모서리 · 그림자

- `--radius-lg` 26px — 폰 프레임
- `--radius-md` 22px — 카드
- `--radius-sm` 10px — 칩/노트
- `--shadow` — 카드가 배경 위에 떠 보이게 하는 부양 그림자 (라이트: `rgba(15,50,52,.20)`, 다크: `rgba(0,0,0,.5)`)

## 핵심 컴포넌트

1. **구간 커버 카드 (시그니처)** — 사진 대신 구간 그라디언트로 채운 커버 + 그 위에 겹쳐 뜨는 흰 정보 패널 + 경계에 걸친 원형 화살표 버튼. 모든 리스트형 카드의 기본 패턴.
2. **타임라인** — 시각(HH:MM) 없이 점(dot)+선(line)+카드 순서로만 방문 순서를 표현. 주차 항목만 골드로 강조.
3. **히어로 배너 + 플로팅 토글** — 상단 앱바를 오렌지 그라디언트 배너로, "전체 여정/오늘" 토글이 배너 경계에 걸쳐 뜸.
4. **하단 내비게이션** — 여행목록 / 전체일정 / 체크리스트 3탭, 활성 탭은 오렌지 필 배경.

## 디자인 규칙

1. 주차는 항상 골드 — 구간 색과 무관하게 고정, "주차" 신호가 절대 흔들리지 않게.
2. 메인 화면은 항상 전체 여정 개요 — 일별 타임라인이 아니라 숙소 단위 구간으로 먼저 보여줌.
3. 시계 시각 표시 금지 — 모든 순서는 타임라인 점 + 카드 순서로만.
4. 구간 색은 2색 그라디언트 세트를 순환 (A→B→C→A…).
5. 배경은 순백 금지, 표면(카드)만 순백 — 흰 면적 과다 인상 방지.
6. 커버형 카드(그라디언트+고스트 아이콘+플로팅 패널)가 이 앱의 시그니처 비주얼.

여행 앱 · Design System v1

지금까지 확정된 디자인을 정리한 시스템

색상 실험(파스텔 → 민트오렌지 → 5색 고정 → 화이트+구간컬러 → Klook 그라디언트)을 거쳐 확정된 토큰과 컴포넌트, 그리고 앞으로도 지켜야 할 디자인 규칙을 한 문서로 모았습니다. 앱을 계속 만들어가면서 이 문서를 기준으로 색/컴포넌트를 재사용하면 됩니다.

01컬러

05디자인 규칙
01
주차는 항상 골드.구간 색이 무엇이든 주차 카드/점/텍스트는 --amber/--pine-strong 고정. "이건 주차"라는 신호가 절대 흔들리지 않아야 함.
02
메인 화면 = 전체 여정 개요.하루 타임라인이 아니라 숙소가 바뀌는 구간 단위로 먼저 보여준다. 일자별 화면은 보조("오늘" 토글).
03
시계 시각(HH:MM) 표시 금지.모든 세부 일정은 타임라인 점 + 카드 순서로만 순서를 표현한다.
04
구간 색은 그라디언트 2색 세트.구간 A/B/C(오렌지, 시안, 틸)를 순환 사용. 커버·날짜배지·아이콘·타임라인 점이 모두 같은 구간 색을 따라간다.
05
배경은 순백 금지, 표면만 순백.--bg는 옅은 웜톤, --surface(카드)만 #FFFFFF로 흰 면적이 과해 보이지 않게 한다.
06
커버형 카드가 시그니처.사진 대신 그라디언트+고스트 아이콘 커버 위에 흰 정보 패널이 겹쳐 뜨는 구조를 모든 리스트형 카드의 기본으로 삼는다.
